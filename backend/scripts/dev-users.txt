Extra roles are never self-service: sign in, go to "My account" > "Add a role" to send a request,
then approve or refuse it as the admin in /admin/role-requests.

Note: affiliate codes are generated randomly. If you reset the database and run the
seed script again, the codes will be different (the script prints the new ones).

Reset the catalogue only (users / roles / settings / audit stay):
  node scripts/seed-dev-users.mjs --reset-catalog

Full reset (also every user, session, role request and audit entry of the LOCAL database):
  docker exec -e PGPASSWORD=webapp_dev webapp-postgres-aspire psql -U webapp -d webapp -c "truncate product_variants, products, product_attributes, product_categories, stores, store_categories, images, platform_settings, role_requests, refresh_tokens, audit_entries, users;"
  node scripts/seed-dev-users.mjs --reset-catalog
